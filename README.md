
# geo-parser-demo

Надёжный демо-скрипт на Python: шаг за шагом собираем данные и сохраняем в Excel. Проект от BuildStep-byte.

## В чём суть подхода

Этот скрипт — не про «быстрый результат любой ценой». Он про то, чтобы данные собирались стабильно, даже если API вернул неполный ответ или район оказался пустым.

## Что делает скрипт

- Проходит по списку районов и имитирует запросы к API.
- Безопасно обрабатывает отсутствующие поля и пустые списки (через `.get()` с заглушками).
- Сохраняет результат в Excel без лишних колонок.
- Добавляет паузы между итерациями — чтобы соответствовать реальным лимитам API.
- Считает средний рейтинг заведений по каждому району и сохраняет его в отдельный файл.

## Результат

После запуска появляется `fastfood_demo.xlsx` со столбцами:

- `district` — район
- `name` — название организации
- `description` — описание
- `rating` — рейтинг (может быть пустым)
Кроме того, скрипт формирует сводный отчёт `avg_rating_by_district.xlsx` со столбцами:

- `district` — район
- `avg_rating` — средний рейтинг заведений в районе
