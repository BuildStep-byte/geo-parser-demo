# geo-parser-demo

Парсер геоданных с двумя режимами работы: демо-версия для отладки и реальная интеграция с API Поиска по организациям (Яндекс).

## Статус API и назначение проекта

Пробный период API истёк, поэтому для демонстрации используется демо‑режим (`main.py`) со статическим датасетом. Код для работы с реальным ключом полностью готов в файле `main_real_api.py`: настроен запрос, обработка JSON‑ответа, валидация полей и обработка возможных ошибок API.

Проект демонстрирует умение разделять логику разработки и интеграции: демо‑режим позволяет тестировать код и показывать результат без API‑ключей, а версия с реальным API готова к подключению через переменные окружения.

## Реализованный функционал

- **Обработка ошибок и стабильность.** Скрипт корректно обрабатывает ошибки сети и неполные ответы API. Для отсутствующих полей используется безопасная выборка через `.get()` с заглушками. Между итерациями добавлены паузы, чтобы соответствовать лимитам API.
- **Агрегация данных.** Выполняется подсчёт средних значений (например, среднего рейтинга заведений) по каждому району.
- **Безопасность и чистота кода.** Ключи API передаются через переменные окружения (`os.environ`). В проекте соблюдается чистый Git‑флоу (ветки, Pull Request, слияние).
- **Экспорт результатов.** Данные сохраняются в Excel‑файлы без лишних колонок.

## Режимы работы

| Файл | Назначение | Особенности |
| --- | --- | --- |
| `main.py` | Демо‑версия | Имитирует ответы сервера. Запускается сразу, без ключей. Идеален для проверки логики, отладки и демонстрации рекрутеру. |
| `main_real_api.py` | Реальная интеграция | Работает с Яндекс Карты Search API. Требует API‑ключ в переменной окружения. Логика обработки ошибок и агрегации данных полностью совпадает с демо‑версией. |
